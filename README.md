# ربات چندکاره تلگرام — Cloudflare Workers + D1

نسخهٔ کامل و عمومی، بدون نام برند و بدون وابستگی به Node.js/Termux در زمان اجرا.

## قابلیت‌ها

- رابط فارسی و منوی Inline
- ارتباط کاربر با مدیریت با دو حالت «با هویت» و «ناشناس»
- دریافت متن، عکس، فایل و سایر پیام‌ها از کاربر
- پاسخ مدیریت به همان کاربر
- واکنش ایموجی از طرف مدیریت
- مسدود کردن کاربر
- ثبت کاربران و سوابق ارتباطی در D1
- آپلودر کانالی: هر فایل یک Deep Link یکتا می‌گیرد
- ارسال فایل با `file_id` تلگرام؛ بدون نیاز به R2 یا هاست فایل
- زمان حذف خودکار پیام فایل در PV
- کپی خودکار پست یک کانال به چند گروه/کانال/PV مقصد
- ساخت منوی دکمه‌ای چندسطحی از داخل ربات
- پاسخ دکمه‌ها می‌تواند هر نوع پیام تلگرامی باشد، نه فقط متن
- فعال/غیرفعال کردن دکمه‌ها و مقصدها
- ویرایش پاسخ دکمه‌ها بدون تغییر کد
- تنظیم متن‌های اصلی از داخل ربات
- تنظیم کانال‌ها، مقصدها و زمان حذف از داخل ربات
- مدیریت ادمین‌های ثانویه
- آمار پایه
- Cron برای حذف خودکار
- Generic: هیچ نام خاصی داخل کد اجباری نشده است

## نکته مهم درباره رنگ دکمه‌ها

Bot API تلگرام برای Inline Keyboard امکان تعیین رنگ دلخواه دکمه را به ربات نمی‌دهد؛ بنابراین رنگ واقعی دکمه‌ها از داخل کد یا پنل قابل کنترل نیست. متن، ساختار، تعداد و رفتار دکمه‌ها قابل کنترل است.

## نصب بدون ترمینال

### 1. ساخت Worker

در Cloudflare Dashboard وارد **Workers & Pages** شوید و یک Worker بسازید.

محتوای `worker.js` را در ادیتور Worker قرار دهید و Deploy کنید.

### 2. ساخت D1

از بخش **Storage & Databases → D1** یک دیتابیس بسازید.

بعد در Worker از بخش **Settings → Bindings** یک D1 Database Binding اضافه کنید:

- Variable name: `DB`
- Database: دیتابیسی که ساختید

سپس محتوای `schema.sql` را یک‌بار در SQL Console همان D1 اجرا کنید.

### 3. Secrets / Variables

در Worker → Settings → Variables and Secrets این مقادیر را اضافه کنید:

#### اجباری

`BOT_TOKEN`

توکن BotFather. بهتر است حتماً به‌صورت Secret ذخیره شود.

`ADMIN_IDS`

شناسه عددی ادمین‌های اصلی، با کاما جداشده؛ مثلاً:

`123456789,987654321`

#### اختیاری ولی توصیه‌شده

`BOT_USERNAME`

یوزرنیم ربات بدون `@`. برای ساخت لینک‌های فایل بهتر است وارد شود.

`WEBHOOK_SECRET`

یک رشته تصادفی برای امنیت بیشتر Webhook.

### 4. Webhook

بعد از Deploy، URL Worker را دارید:

`https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev`

Webhook را روی همین URL قرار دهید. Telegram Bot API از Webhook HTTPS پشتیبانی می‌کند و امکان `secret_token` برای اعتبارسنجی درخواست‌ها نیز دارد.

نمونه درخواست:

`https://api.telegram.org/botYOUR_TOKEN/setWebhook?url=https://YOUR-WORKER.YOUR-SUBDOMAIN.workers.dev&secret_token=YOUR_SECRET`

اگر `WEBHOOK_SECRET` تعریف کرده‌اید، مقدار `secret_token` باید دقیقاً با آن یکسان باشد.

**نکته امنیتی:** توکن واقعی را در لینک عمومی قرار ندهید و پس از تنظیم Webhook آن را در تاریخچه مرورگر یا پیام‌ها منتشر نکنید.

### 5. Cron

در Worker → Settings → Triggers → Cron Triggers یک Cron اضافه کنید:

`*/5 * * * *`

Worker هر پنج دقیقه پیام‌های منقضی‌شده را بررسی و حذف می‌کند. زمان‌بندی Cron در Cloudflare بر اساس UTC اجرا می‌شود.

## تنظیم تلگرام برای قابلیت‌ها

### آپلودر

1. یک کانال را به‌عنوان کانال آپلود انتخاب کنید.
2. ربات را در آن کانال Admin کنید.
3. در پنل ربات، شناسه کانال را در «کانال آپلود» قرار دهید.
4. شناسه چتی که باید لینک‌های ساخته‌شده را دریافت کند در «چت لینک‌ها» قرار دهید.
5. از این پس ارسال فایل در کانال → ساخت لینک یکتا.

### ارسال خودکار

1. ربات را به کانال مبدأ اضافه کنید و دسترسی لازم برای دریافت/پردازش پست‌ها را داشته باشد.
2. در پنل، شناسه کانال مبدأ را تعیین کنید.
3. مقصدها را با شناسه عددی یا `@username` اضافه کنید.
4. هر پست جدید کانال به مقصدهای فعال Copy می‌شود.

برای PV مقصد، آن کاربر باید قبلاً با ربات تعامل کرده باشد تا ربات بتواند برای او پیام ارسال کند.

## پنل مدیریت

با `/start admin` وارد پنل شوید.

### تنظیمات

- کانال آپلود
- چت دریافت لینک‌ها
- کانال مبدأ ارسال خودکار
- زمان حذف خودکار فایل

### متن‌ها

تمام متن‌های عمومی مهم از داخل پنل قابل تغییر هستند.

### دکمه‌های کاربر

برای ساخت دکمه:

1. «دکمه‌های کاربر»
2. «افزودن دکمه»
3. نام دکمه
4. پیام پاسخ دکمه

پیام پاسخ می‌تواند متن، عکس، فایل، ویدئو، صوت و سایر انواع پیام‌های قابل Copy باشد.

برای ساخت مرحله بعدی، داخل صفحه همان دکمه «افزودن زیرمجموعه» را بزنید.

## ارتباط با مدیریت

کاربر ابتدا «ارتباط با مدیریت» را انتخاب می‌کند، سپس حالت را مشخص می‌کند:

- با هویت من
- ناشناس

سپس هر پیام او برای ادمین‌ها ارسال می‌شود. ادمین می‌تواند:

- پاسخ دهد
- واکنش ایموجی بفرستد
- کاربر را مسدود کند

در حالت ناشناس، اطلاعات هویتی در پیام نمایش‌داده‌شده برای ادمین حذف می‌شود؛ شناسه کاربر برای اجرای فنی پاسخ و مدیریت در پایگاه داده نگهداری می‌شود.

## معماری

- Runtime: Cloudflare Workers
- Database: Cloudflare D1
- Scheduler: Cloudflare Cron Trigger
- Storage: Telegram `file_id`
- Transport: Telegram Webhook
- UI: Telegram Inline Keyboard
- Dependencies: صفر در Runtime

## محدودیت‌های مهم Telegram

- ربات نمی‌تواند رنگ دلخواه Inline Keyboard را تعیین کند.
- حذف پیام طبق محدودیت‌های Telegram انجام می‌شود.
- برای ارسال خودکار به PV، کاربر باید قبلاً با ربات تعامل کرده باشد.
- فایل‌ها روی Worker ذخیره نمی‌شوند؛ شناسه فایل تلگرام در D1 نگهداری می‌شود.
- قابلیت‌های کانالی نیازمند تنظیم درست دسترسی ربات در کانال هستند.
