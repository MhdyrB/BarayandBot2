# ربات تلگرامی پیشرفته فارسی — Cloudflare Workers

ربات کامل با این قابلیت‌ها:

- ارتباط دوطرفه کاربر ↔ ادمین (نمایش آیدی + ریپلای)
- آپلودر فایل با لینک یکتا (`t.me/bot?start=f_XXXX`)
- فوروارد خودکار از کانال منبع به گروه(های) هدف
- پنل تنظیمات کامل داخل ربات (متن‌ها، کانال‌ها، آنتی‌اسپم و ...)
- دکمه‌های سفارشی (با دستور `/addbtn`)
- پیام همگانی دسته‌ای (۱۰ تا ۱۰ تا) برای جلوگیری از محدودیت Cloudflare
- آنتی‌اسپم قابل تنظیم
- فورس‌جوین کانال
- مدیریت بلاک / آن‌بلاک
- آمار کاربران

---

## راه‌اندازی سریع

### ۱. پیش‌نیاز
- حساب Cloudflare
- توکن ربات از [@BotFather](https://t.me/BotFather)
- آیدی عددی خودتان (از @userinfobot)

### ۲. ساخت پروژه
```bash
# اگر wrangler ندارید:
npm install -g wrangler
wrangler login
```

### ۳. ساخت KV
```bash
wrangler kv namespace create "BOT_KV"
wrangler kv namespace create "BOT_KV" --preview
```
آیدی‌های خروجی را در `wrangler.toml` جایگزین کنید.

### ۴. تنظیم Secrets
```bash
wrangler secret put BOT_TOKEN
# توکن ربات را وارد کنید

wrangler secret put ADMIN_IDS
# آیدی خودتان (چندتا با کاما)
```

### ۵. استقرار
```bash
wrangler deploy
```

### ۶. تنظیم Webhook
آدرس Worker را باز کنید و به `/setwebhook` بروید:
```
https://YOUR-WORKER.workers.dev/setwebhook
```

## راهنمای استفاده ادمین

بعد از `/start` منوی ادمین ظاهر می‌شود:

| دکمه | کار |
|------|-----|
| ⚙️ تنظیمات | پنل کامل تنظیم متن‌ها، کانال‌ها، آنتی‌اسپم |
| 📤 آپلود فایل | فایل بفرستید → لینک یکتا بگیرید |
| 📢 پیام همگانی | پیام را بفرستید تا به همه ارسال شود |
| 📊 آمار | تعداد کاربران و وضعیت |
| 🚫 مدیریت بلاک | آیدی کاربر برای بلاک/آن‌بلاک |

### افزودن دکمه سفارشی
```
/addbtn متن دکمه | پاسخ متنی اینجا
```
یا برای فایل:
```
/addbtn دریافت فایل | file:کد۸حرفی
```

### تنظیم کانال آپلودر
1. کانال خصوصی بسازید
2. ربات را **ادمین** کنید
3. آیدی عددی کانال را از تنظیمات ربات وارد کنید

---

## نکات مهم
- ربات باید در کانال آپلودر و کانال‌های فورس‌جوین و گروه‌های هدف **ادمین** باشد.
- برای broadcast خیلی بزرگ بعداً می‌توان از Cloudflare Queues استفاده کرد.
- همه تنظیمات از داخل ربات قابل تغییر است و نیازی به ادیت کد نیست.
